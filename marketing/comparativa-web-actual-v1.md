# COMPARATIVA WEB ACTUAL vs DEMO V1.0 — DIMILANO
**Actualizado:** 21/10/2026 · Verificado en https://www.dimilano.es/

## 1. Qué tiene hoy la web de Di Milano

- Web corporativa: Nosotros, Constructora, Inmobiliaria, Actualidad, Talento, Contacto.
- **Listado de inmuebles** (`/nuestros_pisos`) con buscador, 4 filtros, ordenación y fichas (`/inmueble_ind?codigo=…`).
- **Valorador** (`/valorador`): formulario dirección/referencia → estimación.
- Marca cuidada: fotografía de obra, +24 años, +300 proyectos, Instagram y LinkedIn.
- Páginas legales completas.
- ⚠️ El enlace **Portafolio devuelve 404**.

**Lo que no tiene:** capa conversacional, cualificación automática, CRM visible, agenda de visitas, estimador de reformas, radar de mercado, multi-idioma y analítica de leads.

## 5. Argumento de venta (30 segundos)

> “Vuestra web ya enseña muy bien quiénes sois y tiene listado y valorador. Lo que no tiene es la capa que convierte: un agente que atiende 24/7, cualifica, tasa al instante, agenda visitas, las confirma por WhatsApp y lo mete todo en un CRM. No cambiamos vuestra web: le ponemos un cerebro comercial encima.”

**Prioridad recomendada:** inventario real → WhatsApp/agenda → galería/tour → portal de obra.
